PROJECT 01 · DATA MODELLING

Data Modelling Life Expectancy Analysis

An analysis of the WHO Life Expectancy dataset using exploratory data analysis, data preprocessing, and regression models to investigate life expectancy indicators and evaluate prediction performance.

Python Jupyter Notebook Data Analysis Machine Learning

01 / OVERVIEW

Project Overview

This project investigates the WHO Life Expectancy dataset to understand how health, education, and socioeconomic indicators relate to life expectancy. The analysis combines exploratory data analysis with regression modeling to estimate life expectancy and assess predictive performance.

PROJECT TYPE

Academic Project

MAIN FOCUS

Data Analysis & Regression

TOOLS

Python, Pandas, Scikit-learn

02 / EXPLORATORY DATA ANALYSIS

Understanding the Data

Histograms and boxplots were used to examine variable distributions and identify potential outliers. This exploratory analysis helped understand the dataset before preprocessing and regression modeling.

03 / CORRELATION ANALYSIS

Relationships Between Indicators

Correlation analysis was used to examine how life expectancy relates to health, education, and socioeconomic indicators in the WHO dataset.

04 / DATA PREPROCESSING

Preparing the Dataset

The preprocessing workflow included mean imputation for missing numerical values, one-hot encoding for categorical variables, and StandardScaler for feature scaling before regression model evaluation. These steps prepared the dataset for consistent model training and evaluation.

05 / MODELING

Regression Model Comparison

Linear Regression, Decision Tree Regressor, and Random Forest Regressor were evaluated. A tuned Random Forest model was also examined to compare its performance with the baseline model.

06 / MODEL EVALUATION

Actual vs. Predicted

Actual and predicted life expectancy values were compared to evaluate how closely the model's predictions matched the observed values.

MODEL

Baseline Random Forest

R-SQUARED

0.9546

MEAN ABSOLUTE ERROR

1.2913

The reported baseline Random Forest achieved an R² score of 0.9546 and an MAE of 1.2913. The tuned model achieved an R² score of 0.9544 and an MAE of 1.3178, so the baseline performed slightly better on these reported metrics.

07 / CONCLUSION

Key Takeaways

This project provided practical experience in exploratory data analysis, data preprocessing, visualization, and regression modeling. The results demonstrate how machine learning can be applied to investigate patterns in life expectancy data and evaluate predictive performance.
